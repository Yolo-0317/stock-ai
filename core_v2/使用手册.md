# 综合选股策略：全周期牛股捕捉系统 (v2.0)

本策略是一套集成了宏观趋势、主力动向、技术回踩及市场共振的多维度量化选股系统。通过“大盘+板块+个股”三位一体的逻辑，旨在筛选出处于爆发临界点的高胜率品种。

---

## 1. 核心选股逻辑

策略包含四个互补的子逻辑，覆盖了股票从底部启动到强势回调的全周期：

### 1.1 3年大底箱体突破 (Macro Breakout)

* **核心思想**：寻找长期横盘（约3年）后的趋势反转。
* **技术条件**：
  * **箱体周期**：过去 700 个交易日。
  * **箱体宽度**：高低振幅不超过 80%。
  * **突破位置**：当前股价突破过去 700 日箱体顶部。
  * **均线排列**：MA5 > MA10 > MA20（多头排列）。

### 1.2 低位放量三连阳 (Volume Surge)

* **核心思想**：识别主力建仓异动。
* **技术条件**：
  * **价格异动**：连续 3 个交易日收阳线，且每日涨幅 >= 1%。
  * **成交量**：3日内至少有1天成交额超过前5日均值的 1.5 倍。
  * **相对低位**：距离 250 日最高点跌幅超过 30%。

### 1.3 空中加油 (MA20 Pullback)

* **核心思想**：强势股二次拉升机会。
* **技术条件**：
  * **前期强势**：过去 20 个交易日涨幅超过 20%。
  * **缩量回踩**：当前成交量低于 5 日均值的 0.8 倍（缩量）。
  * **支撑确认**：股价回踩至 MA20 附近（距离 < 3%）且未跌破。

### 1.4 早埋伏 (Early Ambush)

* **核心思想**：博弈蓄势待发的突破品种。
* **技术条件**：
  * **临界点**：股价处于 3 年大底箱体顶部下方 1% 至 8% 之间。
  * **趋势向上**：MA20 斜率不为负，且股价站稳 MA20。
  * **量能活跃**：成交量维持在 5 日均值的 0.9 到 1.6 倍之间。

## 2. 评分与共振体系 (100分制)

系统根据多个维度对个股进行实时评分，并根据市场环境动态调整：

| 维度 | 分值范围 | 说明 |
| :--- | :--- | :--- |
| **信号分** | 0 - 45 | 根据触发的子策略（突破、三连阳等）给予基础分。 |
| **趋势分** | 0 - 25 | 考察均线多头排列及股价与 MA20 的位置关系。 |
| **动量分** | 0 - 20 | 考察近期涨幅及波动率，避免“过热”扣分。 |
| **流动性分** | 0 - 10 | 考察成交额，确保有足够的资金深度。 |
| **风险调整** | 0 ~ -15 | 对涨跌幅过大（>8%）或波动率异常的个股进行扣分。 |
| **大盘调整** | -5 / 0 / +5 | **环境溢价**：全市场赚钱效应 >60% 加分，<40% 扣分。 |
| **板块调整** | 0 / +5 | **风口溢价**：个股所属行业处于当日热门板块前 5 名。 |
| **共振加分** | 0 / +10 | **三力合一**：大盘好 + 属于热点板块 + 个股信号强。 |

## 3. 仓位管理建议

系统根据最终得分给出操作建议，并自动计算建议买入股数（假设总本金 100,000 元）：

| 建议动作 | 推荐仓位 | 逻辑说明 |
| :--- | :--- | :--- |
| **强势关注** | **20%** | 三力合一或多项指标满分，高置信度进攻。 |
| **观察买入** | **15%** | 核心信号明确，趋势良好，适合建立主力仓位。 |
| **继续观察** | **8%** | 信号存在但共振不足，建议建立底仓观察。 |
| **小仓埋伏** | **5%** | 针对“早埋伏”品种，博弈突破，轻仓参与。 |
| **谨慎回避** | **0%** | 评分过低或风险过大，不建议操作。 |

## 4. 数据架构与获取机制

本系统采用“本地历史+实时抓取”的双引擎架构，确保扫描的高效性与时效性。

### 4.1 历史 K 线数据 (核心计算源)

* **来源**：本地 MySQL 数据库 (`stock_data` 库中的 `stock_daily` 表)。
* **内容**：全 A 股过去 3-5 年的开盘、最高、最低、收盘价、成交量、成交额及涨跌幅。
* **获取技术**：通过 `SQLAlchemy` 建立长连接，利用原生 SQL 语句一次性加载海量数据至内存。

### 4.2 实时情绪与板块数据 (风向标)

* **来源**：通过开源库 `AkShare` 实时抓取。
* **接口详情**：
  * **指数行情**：抓取自东方财富 (Eastmoney) 或新浪财经 (Sina) 的公开 API。
  * **涨跌分布**：实时统计全市场上涨/下跌家数，计算赚钱效应。
  * **热门板块**：抓取东方财富行业板块实时涨幅排名。
* **稳定性设计**：
  * **多源兜底**：内置多源抓取机制，当首选接口（如东财）异常时，自动切换至备选源（如新浪）。
  * **人工干预 (Manual Fallback)**：当所有自动化接口因验证码或封禁失效时，支持切换至浏览器模拟模式。在 Cursor 环境下，我将直接调用浏览器工具并截屏，若出现验证码，你可以直接在对话中辅助我完成验证，确保极端情况下数据获取的连续性。

### 4.3 基础信息与行业映射

* **行业映射**：优先从本地 `stock_basic` 表读取；若缺失，则通过 `ak.stock_individual_info_em` 实时补全。

## 5. 系统执行流程与技术设计

### 5.1 执行步骤

1. **环境初始化**：加载 `.env` 配置，建立数据库连接池。
2. **获取大盘情绪**：调用 `core_v2/fetch_akshare_data.py` 中的 `get_market_sentiment` 抓取指数、分布及热门行业。
3. **海量数据加载**：从 `stock_daily` 表加载所有个股过去 1100 天的 K 线记录（约 380 万条）。
4. **个股并行扫描**：通过 `core_v2/stock_selection_combined.py` 执行：
    * **基础过滤**：剔除价格异常（<5元或>20元）及流动性不足（成交额<5000万）的个股。
    * **指标计算**：利用 Pandas 向量化计算 MA 均线及波动率。
    * **逻辑判定**：匹配四大算法模块（大底突破、三连阳、空中加油、早埋伏）。
5. **共振评分引擎**：综合大盘、板块、个股信号，计算最终得分及“三力合一”标识。
6. **量化仓位计算**：按 A 股 100 股整数倍规则自动计算建议买入股数。
7. **结果持久化**：导出带时间戳的 CSV 报告。

### 5.2 技术设计要点

* **高性能计算**：全量指标计算采用 **Pandas 向量化操作**，避免 Python 原生循环，380 万条数据扫描仅需 2-3 分钟。
* **数据库层**：采用 ORM 与原生 SQL 结合，确保大数据量查询的稳定性。
* **模块化架构**：选股算法与评分引擎完全解耦，支持子策略的快速增删与权重调整。

---

## 6. 执行指南

1. **运行频率**：建议每日收盘后或盘中实时运行。
2. **止损原则**：
    * **大底突破**：跌回箱体顶部下方 3% 止损。
    * **空中加油/早埋伏**：有效跌破 MA20 且 3 日内无法收回止损。

## 7. `core_v2` 脚本能力介绍

`core_v2` 目录是系统的核心作战室，包含了从全量选股到个股深度解剖的所有关键脚本。

### 7.1 `sync_tushare_daily_to_mysql.py` (数据同步助手)

* **核心能力**：从 Tushare 接口自动化增量拉取全 A 股日线数据并同步至 MySQL。
* **功能特点**：
  * **增量更新**：自动检测数据库最新日期，仅拉取缺失数据。
  * **限流保护**：内置 RateLimiter，严格遵守 Tushare 的 API 调用频率限制。
  * **多模式支持**：支持按日期回溯（by_date）或全量初始化（full）。
* **用途**：作为选股扫描的前置步骤，确保分析基于最新的收盘数据。

### 7.2 `stock_selection_combined.py` (全量选股引擎)

* **核心能力**：执行全市场 5000+ 只股票的自动化扫描。
* **集成逻辑**：
  * **四大策略**：大底突破、三连阳、空中加油、早埋伏。
  * **三力合一**：自动集成大盘情绪加分、热门板块风口加分及个股形态共振。
  * **量化输出**：直接输出建议动作（如“强势关注”）、建议买入股数及预计金额。
* **用途**：每日收盘后或盘中寻找高胜率交易机会。

### 7.2 `analyze_specific_stocks.py` (全维度 AI 决策)

* **核心能力**：对特定股票进行“定性分析”。
* **数据聚合**：整合基本面（PE/ROE）、资金面（主力流向）、消息面（最新新闻）及技术面。
* **AI 推理**：调用 DeepSeek-V3 模型，通过深度 Prompt 识别主力意图，给出包含买入区间和止损位的实战报告。
* **用途**：对选股结果进行最后的“专家级”审核。

### 7.3 `analyze_stock.py` (技术面深度解剖)

* **核心能力**：对特定股票进行“定量分析”。
* **均线系统**：深度解剖 MA5/10/20/60 均线，计算乖离率、均线增长率及多头排列状态。
* **回踩判定**：自动识别股价是否精准触碰关键支撑位（如 MA5）。
* **用途**：精确寻找个股的入场点和防守位。

### 7.4 `get_realtime_quote.py` (极速行情接口)

* **核心能力**：秒级延迟行情抓取。
* **技术实现**：直接对接东方财富底层数据接口，绕过网页渲染，获取最纯净的价格、涨跌幅及成交额数据。
* **用途**：为 AI 分析和盘中决策提供最及时的价格参考。

### 7.5 `fetch_akshare_data.py` (数据采集中心)

* **核心能力**：多源数据抓取与健壮性保障。
* **覆盖范围**：大盘指数、全 A 股涨跌分布、行业板块排名、个股基本面及新闻。
* **兜底机制**：内置多源自动切换（东财/新浪/同花顺）及浏览器/人工干预模式，确保数据获取永不断供。
* **用途**：作为所有分析脚本的底层数据供应引擎。

### 7.6 `_bootstrap.py` (环境引导助手)

* **核心能力**：路径自动化管理。
* **功能**：确保脚本在 `core_v2` 目录下运行时，能正确识别并导入项目根目录的模块（如 `tushare_mcp.py`）。
* **用途**：解决 Python 跨目录导入的路径问题。
