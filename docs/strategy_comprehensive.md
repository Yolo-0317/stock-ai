# 综合选股策略：全周期牛股捕捉系统 (v2.0)

本策略是一套集成了宏观趋势、主力动向、技术回踩及市场共振的多维度量化选股系统。通过“大盘+板块+个股”三位一体的逻辑，旨在筛选出处于爆发临界点的高胜率品种。

---

## 1. 核心选股逻辑

策略包含四个互补的子逻辑，覆盖了股票从底部启动到强势回调的全周期：

### 1.1 3年大底箱体突破 (Macro Breakout)
*   **核心思想**：寻找长期横盘（约3年）后的趋势反转。
*   **技术条件**：
    *   **箱体周期**：过去 700 个交易日。
    *   **箱体宽度**：高低振幅不超过 80%。
    *   **突破位置**：当前股价突破过去 700 日箱体顶部。
    *   **均线排列**：MA5 > MA10 > MA20（多头排列）。

### 1.2 低位放量三连阳 (Volume Surge)
*   **核心思想**：识别主力建仓异动。
*   **技术条件**：
    *   **价格异动**：连续 3 个交易日收阳线，且每日涨幅 >= 1%。
    *   **成交量**：3日内至少有1天成交额超过前5日均值的 1.5 倍。
    *   **相对低位**：距离 250 日最高点跌幅超过 30%。

### 1.3 空中加油 (MA20 Pullback)
*   **核心思想**：强势股二次拉升机会。
*   **技术条件**：
    *   **前期强势**：过去 20 个交易日涨幅超过 20%。
    *   **缩量回踩**：当前成交量低于 5 日均值的 0.8 倍（缩量）。
    *   **支撑确认**：股价回踩至 MA20 附近（距离 < 3%）且未跌破。

### 1.4 早埋伏 (Early Ambush)
*   **核心思想**：博弈蓄势待发的突破品种。
*   **技术条件**：
    *   **临界点**：股价处于 3 年大底箱体顶部下方 1% 至 8% 之间。
    *   **趋势向上**：MA20 斜率不为负，且股价站稳 MA20。
    *   **量能活跃**：成交量维持在 5 日均值的 0.9 到 1.6 倍之间。

## 2. 评分与共振体系 (100分制)

系统根据多个维度对个股进行实时评分，并根据市场环境动态调整：

| 维度 | 分值范围 | 说明 |
| :--- | :--- | :--- |
| **信号分** | 0 - 45 | 根据触发的子策略（突破、三连阳等）给予基础分。 |
| **趋势分** | 0 - 25 | 考察均线多头排列及股价与 MA20 的位置关系。 |
| **动量分** | 0 - 20 | 考察近期涨幅及波动率，避免“过热”扣分。 |
| **流动性分** | 0 - 10 | 考察成交额，确保有足够的资金深度。 |
| **风险调整** | 0 ~ -15 | 对涨跌幅过大（>8%）或波动率异常的个股进行扣分。 |
| **大盘调整** | -5 / 0 / +5 | **环境溢价**：全市场赚钱效应 >60% 加分，<40% 扣分。 |
| **板块调整** | 0 / +5 | **风口溢价**：个股所属行业处于当日热门板块前 5 名。 |
| **共振加分** | 0 / +10 | **三力合一**：大盘好 + 属于热点板块 + 个股信号强。 |

## 3. 仓位管理建议

系统根据最终得分给出操作建议，并自动计算建议买入股数（假设总本金 100,000 元）：

| 建议动作 | 推荐仓位 | 逻辑说明 |
| :--- | :--- | :--- |
| **强势关注** | **20%** | 三力合一或多项指标满分，高置信度进攻。 |
| **观察买入** | **15%** | 核心信号明确，趋势良好，适合建立主力仓位。 |
| **继续观察** | **8%** | 信号存在但共振不足，建议建立底仓观察。 |
| **小仓埋伏** | **5%** | 针对“早埋伏”品种，博弈突破，轻仓参与。 |
| **谨慎回避** | **0%** | 评分过低或风险过大，不建议操作。 |

## 4. 执行指南

1.  **运行频率**：建议每日收盘后或盘中实时运行。
2.  **数据依赖**：
    *   `stock_daily`: 历史 K 线数据库。
    *   `AkShare`: 实时大盘、板块及基本面接口。
3.  **止损原则**：
    *   **大底突破**：跌回箱体顶部下方 3% 止损。
    *   **空中加油/早埋伏**：有效跌破 MA20 且 3 日内无法收回止损。
