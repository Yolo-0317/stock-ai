# 📊 选股策略使用指南

## 🎯 策略概述

**策略名称**：量价齐升突破选股

**策略类型**：日线级别、短中线波段

**运行时机**：每日收盘后（15:30 之后，确保当日数据已更新）

---

## 📐 策略逻辑

### 核心思想

寻找**成交量放大 + 价格突破**的股票，这类股票通常具有：
- 主力资金介入迹象（放量）
- 趋势向上明确（多头排列）
- 尚未过度炒作（涨幅可控）

### 筛选条件

#### 1️⃣ 基础过滤
```
✓ 交易所：只选沪深股票（SZ/SH），排除北交所
✓ 价格区间：5元 ≤ 收盘价 ≤ 30元
✓ 成交额：> 5000万（确保流动性）
✓ 数据要求：至少65个交易日历史数据
```

#### 2️⃣ 策略条件
```
✓ 今日涨幅：3% - 9%
  - 有力度但不疯狂
  - 不排除涨停板（给激进者机会）

✓ 放量确认：量比 > 1.5
  - 量比 = 今日成交量 / 近5日平均成交量
  - 放量说明主力活跃

✓ 多头排列：收盘价 > MA5 > MA20 > MA60
  - 短中长期均线向上
  - 趋势明确

✓ 防止追高：近5日累计涨幅 < 20%
  - 避免追在高位
  - 留有上涨空间
```

#### 3️⃣ 排序规则
```
按量比降序排列
- 量比越大，主力越活跃
- 优先关注量比最高的股票
```

## 🚀 使用方法

### 1. 环境准备

确保已配置环境变量：

```bash
# .env 文件
MYSQL_URL=mysql+pymysql://user:password@host:port/database
```

### 2. 数据准备

**重要**：选股依赖最新的日线数据，请确保：

```bash
# 每日收盘后更新数据（15:30 之后）
uv run python scripts/sync_tushare_daily_to_mysql.py

# 或使用便捷脚本
./run_sync_daily.sh
```

### 3. 运行选股

```bash
# 使用最新交易日数据
uv run python scripts/stock_selection.py

# 指定历史日期（回测）
uv run python scripts/stock_selection.py --date 20260107
```

### 4. 查看结果

结果保存在：`output/stock_selection_YYYYMMDD.csv`

**输出字段**：
```
排名 | 代码 | 名称 | 收盘价 | 涨幅% | 量比 | MA5 | MA20 | MA60 | 5日涨幅% | 距30日高点% | 成交额(万)
```

---

## 📊 结果解读

### 关键指标说明

#### 量比（Volume Ratio）
- **含义**：今日成交量 / 近5日平均成交量
- **解读**：
  - 量比 > 2：显著放量，主力活跃
  - 量比 1.5-2：温和放量
  - 量比 < 1.5：不符合策略

#### 5日涨幅
- **含义**：近5个交易日的累计涨幅
- **解读**：
  - < 10%：温和上涨，安全
  - 10%-15%：正常强势
  - 15%-20%：较强，需谨慎
  - > 20%：不符合策略（已过滤）

#### 距30日高点
- **含义**：当前价格距离近30日最高价的距离
- **解读**：
  - -5% 以内：接近前期高点，可能突破
  - -10% 以内：有一定空间
  - < -10%：距离高点较远，空间大

## 💡 操作建议

### 使用原则

1. **参考，不盲从**
   - 选股结果是辅助工具
   - 结合自己的判断和市场环境

2. **分散投资**
   - 不要all-in单只股票
   - 建议选择3-5只分散风险

3. **设置止损**
   - 买入后设置止损位（如 -5%）
   - 严格执行，保护本金

4. **关注排名靠前的**
   - 量比越高，主力越活跃
   - 优先关注Top10

### 买入时机

**建议**：不要在选股当天就买入，而是：

1. **第二天观察**
   - 开盘后观察走势
   - 是否继续放量
   - 是否回调到支撑位

2. **分批买入**
   - 第一次买入30-50%仓位
   - 确认趋势后加仓

3. **设置买入价位**
   - 回调到MA5附近
   - 或突破前期高点时

### 卖出时机

1. **止盈**
   - 涨幅达到10-15%考虑减仓
   - 涨幅达到20%以上考虑清仓

2. **止损**
   - 跌破MA5考虑减仓
   - 跌破买入价5%止损

3. **趋势转弱**
   - MA5下穿MA20（死叉）
   - 量能萎缩

## 🔧 参数调整

如果您想调整策略参数，可以修改 `scripts/stock_selection.py` 中的配置：

```python
# 策略参数（文件顶部）
MIN_PRICE = 5.0              # 最低价格
MAX_PRICE = 30.0             # 最高价格
MIN_AMOUNT = 5000.0          # 最低成交额（万元）
MIN_PCT_CHG = 3.0            # 最低涨幅（%）
MAX_PCT_CHG = 9.0            # 最高涨幅（%）
VOLUME_RATIO = 1.5           # 量比阈值
MAX_5D_CHG = 20.0            # 近5日最大涨幅（%）
MIN_HISTORY_DAYS = 65        # 最少历史数据天数
```

**常见调整**：

1. **更保守**：
   - `VOLUME_RATIO = 2.0`（要求更强放量）
   - `MAX_5D_CHG = 15.0`（更严格的追高限制）

2. **更激进**：
   - `MAX_PCT_CHG = 12.0`（允许更高涨幅）
   - `VOLUME_RATIO = 1.3`（放宽放量要求）

3. **调整价格区间**：
   - 只选低价股：`MIN_PRICE = 3.0, MAX_PRICE = 10.0`
   - 只选中高价股：`MIN_PRICE = 10.0, MAX_PRICE = 50.0`

## ⚠️ 风险提示

1. **历史数据不代表未来**
   - 策略基于历史规律
   - 市场环境变化可能导致策略失效

2. **不保证盈利**
   - 任何策略都有失败的时候
   - 严格止损，控制风险

3. **市场环境影响**
   - 牛市：策略成功率高
   - 熊市：谨慎使用，减少仓位
   - 震荡市：适度参与

4. **个股风险**
   - 关注公司基本面
   - 避免踩雷（财务造假、重大利空等）
