# 📈 沿MA5上行回调买入策略指南

## 🎯 策略概述

**策略名称**：沿MA5上行回调买入选股

**策略类型**：日线级别、波段操作

**运行时机**：每日收盘后（15:30 之后，确保当日数据已更新）

**核心思想**：寻找"刚好回踩MA5准备反弹"的股票，这类股票具有：
- 明确的支撑位（MA5）
- 精准的买入点（回踩MA5）
- 清晰的止损位（跌破MA5）
- 较高的成功率（MA5支撑有效）

---

## 📐 策略逻辑

### 为什么选择"贴着MA5上行"的股票？

#### 1️⃣ 主力控盘强
- 股价能沿着MA5稳健上行，说明主力有计划地拉升
- 不是暴涨暴跌，而是温和上涨
- 每次回调都在MA5处获得支撑

#### 2️⃣ 买点精准
- 回踩MA5是天然的买入点
- 不用追高，等回调到位再买
- 风险收益比好

#### 3️⃣ 止损明确
- MA5就是止损位
- 跌破MA5说明趋势可能转弱
- 及时止损，保护本金

#### 4️⃣ 趋势明确
- MA5向上说明短期趋势向上
- 多头排列说明中长期趋势也向上
- 顺势而为，成功率高

## 📋 筛选条件详解

### 基础过滤

```
✓ 交易所：只选沪深股票（SZ/SH），排除北交所
✓ 价格区间：5元 ≤ 收盘价 ≤ 30元
✓ 成交额：> 5000万（确保流动性）
✓ 数据要求：至少65个交易日历史数据
```

### 核心条件

#### 1️⃣ 今日收盘价与MA5的乖离率：-2% 到 +1%

**含义**：今天的收盘价刚好在MA5附近或略低

**为什么这样设置？**
- 乖离率 -2% 到 0%：略低于MA5，可能是回踩支撑
- 乖离率 0% 到 +1%：刚好在MA5上方，非常贴合
- 超出这个范围：要么离MA5太远，要么跌破太多

**计算方式**：
```
乖离率 = (今日收盘价 - 昨日MA5) / 昨日MA5 × 100%
```

注意：这里用的是**昨日的MA5**（不包括今天），更客观

---

#### 2️⃣ 今日最低价触碰MA5（±1%以内）

**含义**：今天盘中有回踩MA5的动作

**为什么重要？**
- 说明今天确实测试了MA5的支撑
- 如果MA5支撑有效，次日可能反弹
- 这是一个关键的技术信号

**判断标准**：
```
今日最低价相对昨日MA5的乖离率 ≤ 1%
```

---

#### 3️⃣ 今日收阳线（收盘价 > 开盘价）

**含义**：今天尾盘拉起，收盘价高于开盘价

**为什么重要？**
- 说明回踩后有反弹动作
- 尾盘拉起说明主力护盘
- 收阳线是反转信号

**典型形态**：
- 早盘或盘中回踩MA5
- 尾盘拉起，收复失地
- 留下下影线，说明支撑有效

---

#### 4️⃣ 近5日中，至少3天收盘价在MA5上方

**含义**：之前是强势的，不是今天才涨起来

**为什么重要？**
- 说明这只股票一直在MA5上方运行
- 今天的回踩是正常调整，不是趋势转弱
- 有历史强势基础

**判断方式**：
- 统计近5个交易日（不包括今天）
- 计算每天的收盘价相对当天MA5的位置
- 至少3天在MA5上方

---

#### 5️⃣ MA5向上（今日MA5 > 5日前的MA5，且增长率>2%）

**含义**：MA5本身在向上移动，不是平的或向下的

**为什么重要？**
- 只有MA5向上，"贴着MA5"才有意义
- 如果MA5是平的，说明股价在震荡
- 如果MA5向下，说明趋势转弱

**计算方式**：
```
MA5增长率 = (今日MA5 - 5日前的MA5) / 5日前的MA5 × 100%
要求增长率 > 2%
```

---

#### 6️⃣ 近10日涨幅 > 5%

**含义**：有上涨趋势，不是横盘或下跌

**为什么重要？**
- 确保股票处于上升通道
- 不是底部横盘，而是已经启动
- 有一定的上涨动能

---

#### 7️⃣ 多头排列：MA5 > MA20 > MA60

**含义**：短中长期均线都向上排列

**为什么重要？**
- 说明趋势明确向上
- 不仅短期强势，中长期也看好
- 多头排列是强势股的标志

---

### 排序规则

**按乖离率绝对值排序（越接近0%越好）**

**为什么这样排序？**
- 乖离率越接近0%，说明越"贴着"MA5
- 这样的股票支撑更明确
- 买入点更精准

**示例**：
- 乖离率 -0.5%：排名第1（最贴合）
- 乖离率 +0.8%：排名第2
- 乖离率 -1.5%：排名第3
- 乖离率 +1.0%：排名第4

## 📊 结果解读

### 关键指标说明

#### 乖离率%
- **含义**：今日收盘价相对昨日MA5的偏离程度
- **解读**：
  - -0.5% ~ 0%：略低于MA5，最佳买点
  - 0% ~ +0.5%：刚好在MA5上，也很好
  - -1% ~ -2%：稍微偏离，需观察
  - +0.5% ~ +1%：略高于MA5，可能要回调

#### MA5增长率%
- **含义**：MA5向上的速度
- **解读**：
  - 2% ~ 3%：温和上涨，稳健
  - 3% ~ 5%：较快上涨，强势
  - > 5%：快速上涨，可能过热

#### 5日强势天数
- **含义**：近5日中有多少天在MA5上方
- **解读**：
  - 5天：非常强势，一直在MA5上方
  - 4天：强势，偶尔回踩
  - 3天：合格，有一定强势基础

#### 10日涨幅%
- **含义**：近10个交易日的累计涨幅
- **解读**：
  - 5% ~ 10%：温和上涨，健康
  - 10% ~ 15%：较强上涨，注意回调风险
  - > 15%：快速上涨，可能需要调整

## 💡 操作建议

### 买入时机

**不要选股当天就买入！** 建议：

#### 方式一：次日低开买入
- 如果次日低开，回踩MA5附近
- 观察分时图，如果有反弹迹象
- 可以在MA5附近买入

#### 方式二：次日突破买入
- 如果次日高开或平开
- 观察能否突破昨日高点
- 突破后回踩不破，可以买入

#### 方式三：等待再次回踩
- 如果次日大涨，不追
- 等待再次回踩MA5
- 回踩到位再买入

### 仓位管理

1. **分批买入**
   - 第一次买入30-50%仓位
   - 确认趋势后加仓

2. **分散投资**
   - 选择3-5只股票
   - 不要集中在一只

3. **控制总仓位**
   - 这个策略的股票总仓位不超过50%
   - 留有现金应对风险

### 止损设置

**止损位：跌破MA5**

具体操作：
- 如果收盘价跌破MA5超过2%，考虑止损
- 如果连续2天收盘价在MA5下方，坚决止损
- 止损后不要心存侥幸，严格执行

### 止盈设置

**止盈策略**：
- 涨幅达到5-8%，减仓50%
- 涨幅达到10-15%，清仓或留底仓
- 如果股价远离MA5（乖离率>5%），考虑减仓

## 🔧 参数调整

如果您想调整策略参数，可以修改 `scripts/stock_selection_ma5.py` 中的配置：

```python
# 策略参数（文件顶部）
MIN_PRICE = 5.0              # 最低价格
MAX_PRICE = 30.0             # 最高价格
MIN_AMOUNT = 5000.0          # 最低成交额（万元）
MIN_DEVIATION = -2.0         # 最小乖离率（%）
MAX_DEVIATION = 1.0          # 最大乖离率（%）
TOUCH_THRESHOLD = 1.0        # 触碰MA5的阈值（%）
MIN_DAYS_ABOVE_MA5 = 3       # 近5日中至少N天在MA5上方
MA5_GROWTH_RATE = 2.0        # MA5增长率（%）
MIN_10D_CHG = 5.0            # 近10日最小涨幅（%）
```

**常见调整**：

1. **更严格（更少但更精准）**：
   - `MIN_DEVIATION = -1.0, MAX_DEVIATION = 0.5`（更贴近MA5）
   - `MIN_DAYS_ABOVE_MA5 = 4`（要求更强势）
   - `MA5_GROWTH_RATE = 3.0`（要求MA5更陡）

2. **更宽松（更多选择）**：
   - `MIN_DEVIATION = -3.0, MAX_DEVIATION = 2.0`（允许更大偏离）
   - `MIN_DAYS_ABOVE_MA5 = 2`（降低强势要求）
   - `MIN_10D_CHG = 3.0`（降低涨幅要求）

## 📈 与策略一的对比

| 维度 | 策略一（量价齐升） | 策略二（沿MA5上行） |
|------|-------------------|---------------------|
| **目标** | 找启动点 | 找买点 |
| **涨幅要求** | 3%-9%（较大） | 可能较小 |
| **放量要求** | 量比>1.5（明显放量） | 不要求 |
| **形态特征** | 突破关键位 | 回踩MA5 |
| **买入时机** | 突破时追涨 | 回调时低吸 |
| **持股周期** | 3-7天（短线） | 1-3周（波段） |
| **止损位** | 相对模糊 | 明确（MA5） |
| **风险** | 中高 | 中 |
| **收益** | 高 | 中 |
| **成功率** | 中 | 较高 |

**建议**：
- 两个策略可以同时使用
- 策略一适合激进投资者
- 策略二适合稳健投资者
- 或者策略一找票，策略二找买点

## ⚠️ 风险提示

1. **MA5不是万能的**
   - 有时MA5支撑会失效
   - 特别是在大盘暴跌时
   - 严格止损很重要

2. **假突破风险**
   - 有的股票回踩MA5后继续下跌
   - 需要结合大盘环境判断
   - 不要盲目抄底

3. **市场环境影响**
   - 牛市：策略成功率高
   - 熊市：谨慎使用，减少仓位
   - 震荡市：最适合这个策略

4. **个股风险**
   - 关注公司基本面
   - 避免踩雷（利空、减持等）
   - 不要只看技术面

## 🎓 进阶技巧

### 1. 结合分时图

在东方财富查看分时图：
- 观察今天是什么时候回踩MA5的
- 早盘回踩好于尾盘回踩
- 回踩后快速拉起好于缓慢拉起

### 2. 观察成交量

虽然策略不要求放量，但：
- 回踩时缩量好于放量（说明抛压不大）
- 拉起时放量好于缩量（说明有资金接盘）

### 3. 关注板块

- 如果所属板块也在走强，成功率更高
- 如果是板块龙头，更值得关注
- 避免冷门板块的个股

### 4. 次日验证

- 次日开盘后观察5-10分钟
- 如果低开后快速拉起，是好信号
- 如果低开后继续下跌，放弃
